# MoonDesk · 月面照片检查

MoonDesk 是用于比较同一次观测的短长曝光照片、检查月盘亮度和留存源坐标检查记录的本地工作台。

运行 `./start.sh` 后打开 [MoonDesk](http://127.0.0.1:19890/)。运行 `./start.sh stop` 停止服务，保留容器卷。

## 月面工作台

- 导入主照片和可选的对照照片。对照图须由使用者预先对齐，且转换到相同像素尺寸。
- 在源图上点击单个像素核对 RGB 和近似显示亮度，或下载所用照片。
- 框定月盘的椭圆外接矩形和需要分析的检查窗。另有独立亮暗参照框可画。
- 受光统计可选用「按明暗界」或「按亮度门槛」两种依据，并可随时切回门槛统计。填写角秒每像素后可读角面积。
- 明暗横扫在检查窗内逐行寻找亮侧指向暗侧的亮度台阶，再把候选串成一条连续明暗界：每行最多采用一个界点。
  长而弱的连续边与短而强的偏折同时说得通时优先采用长边，偏折段只作为「未采用」候选并列在行内，说明栏会写出采用段、理由和未采用段。
  没有合格候选的行留空并计入待确认面积，不会用平滑线补接。
- 亮度剖线、亮暗参照、亮度分布与剪切检查用于定位纹理变化、比较照度和检查黑白剪切。
- 保留参数供之后使用，或保存一份带源照片标识的检查。存档可复查源像素并下载 CSV 和标记 PNG。
- 照片准备可独立导入和处理照片，并把尺寸相同的准备结果带回当前观测，供对照检查。

支持不透明、单帧 PNG 和 JPEG。单张上传最大 14 MiB，图像至少 8×8，总像素至多 400 万。载入的练习是带近似月壤纹理的合成素材。

受光统计是显示亮度的图面测量。按明暗界统计时，采用界点两侧分别计入亮区与暗区，留空行在月盘内的像素计入待确认；按亮度门槛统计时，待确认恒为 0，可与旧读数对照。两种依据都受曝光和月盘标记影响，不用于精密月相或地形推算。标记使用像素坐标，角面积由输入的像素尺度计算。本地服务只绑定 127.0.0.1。
